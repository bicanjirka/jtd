Next-gen Upgrade Panels

Every tower's Upgrades panel as the game paints it today, with each node's real hover sheet. A tower with a next-gen feature doc also gets its new tree, read from that doc's tables: tiers that climb from the bottom, each opened by a gate. The mock is live. Click a node to buy it, right-click to downgrade it, and use Meet gate to open the next tier.

Tier unlock
Phase

Square: a stat node. It changes a number or improves something the tower already has.

Round: an ability node. It adds a new ability or skill and takes the tier's colour, so shape and colour both say it.

Dashed frame: a cluster. Bought once, you keep one member. Switching is free between waves.

Grey band: a locked tier. Its gate sits on the tier's floor and shows what is missing.

Generated by td.ui.PreviewUpgrades (run-jtd). Current panels come from a fresh tower on The Amber Hive with gates on, painted headless by the game's own PanelUpgradeTree and TooltipPanel. Each next-gen tree is read from the tables in docs/features/FEATURE-next-gen-<tower>-tower.md; the full dead-code list is in ledger.md beside this page.
